
# cafe origen - analisis de ventas

proyecto de analisis de ventas de cafe origen desarrollado con javascript. en este proyecto se trabajan 12 registros de ventas utilizando arreglos, objetos, ciclos y funciones.

## archivos del proyecto

- src/datos.js: contiene los 12 registros de ventas.
- src/explorar.js: muestra la informacion de las ventas.
- src/analitica.js: contiene las funciones para analizar las ventas.
- src/reporte.js: ejecuta las funciones y muestra los resultados.
- patrones/: contiene ejemplos y guias de los temas trabajados.
- bitacora.md: contiene el diccionario de datos y el desarrollo de los miniretos.

## mini reto 1 - exploracion de datos

se crearon los 12 registros de ventas utilizando arreglos y objetos de javascript. tambien se reviso la informacion para conocer los datos disponibles.

## mini reto 2 - ciclos manuales

se crearon funciones para calcular el total vendido, las unidades vendidas, la venta de mayor valor, las ventas por ciudad y el promedio por venta. tambien se realizaron pruebas con diferentes datos.

## mini reto 3 - metodos de arreglos y diccionarios

se crearon cinco funciones para filtrar las ventas validas, crear un resumen, calcular el total por ciudad, contar las unidades por producto y mostrar los tres productos que mas dinero generaron.

## mini reto 4 - verificacion del reporte

se creo el archivo reporte.js para ejecutar las funciones y mostrar los resultados. tambien se comprobo que las 12 ventas originales conservaran su cantidad.

## como ejecutar el proyecto

para explorar las ventas:

node src/explorar.js

para ejecutar el reporte completo:

node src/reporte.js

practicar javascript mediante el analisis de ventas, utilizando ciclos, funciones, arreglos y objetos para organizar la informacion y obtener resultados.
