
------cafe origen - mini reto 1----

proyecto de analisis de ventas de cafe origen
en este proyecto se guardan 12 registros de ventas usando arreglos y objetos de javascript

archivos del proyecto:
datos.js: contiene los datos de las ventas
explorar.js: muestra la informacion de las ventas
analitica.js: archivo creado para el proyecto
bitacora.md: contiene el diccionario de datos y los casos encontrados

para ejecutar el proyecto
node src/explorar.js
